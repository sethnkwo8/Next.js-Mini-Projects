# Next.js Mini Projects

This repository contains a collection of Next.js mini projects built to deeply understand modern Next.js architecture, server-first development, and full-stack workflows.

Each project is self-contained, has its own README, and focuses on a specific set of concepts.

---

## 🧩 Projects Overview

## 1️⃣ Blog App - Server Actions & Middleware Auth

**Folder**: blog-feed-platform/

A blog application demonstrating modern Next.js App Router features, including:
-	Server Components
-	Client Components
-	Server Actions
-	Form Actions
-	Cookie-based authentication
-	Middleware route protection
-	Cache revalidation
-	Layouts and metadata
-	Streaming & loading behavior

📄 See the project README inside the folder for full details.


## 2️⃣ Auth-Protected Dashboard (Next.js App Router)

**Folder**: auth-protected-dashboard/

An auth protected dashboard demonstrating modern Next.js App Router features, including:
- Server-side authentication
- Route protection with middleware
- Server-first architecture
- Clean project structure
- Modern Next.js patterns

📄 See the project README inside the folder for full details.

💡 Each mini project is intentionally small and concept-driven to ensure mastery before moving to larger applications.
